## 📝 Conventions used in filenames

| Prefix | Meaning |
|---|---|
| `[Guide] *` | Long-form how-to or methodology document |
| `[Tips-and-Tricks] *` | Short, tactical, single-topic tip |
| `[Resources] *` | Curated index of external resources on a topic |
| `[Mindmap] *` | Visual / diagrammatic reference |

Filenames preserve the original space-prefix convention (`[Tag] filename.md`) for backward compatibility with existing links and bookmarks.

## 🔄 How this directory evolves

- **`awesome-stars.md`** is **regenerated periodically** (~monthly) from my live GitHub starred list. Categories are auto-classified then manually reviewed.
- **Guides** and **Tips-and-Tricks** are added as I encounter situations worth documenting.
- **Mindmaps** are stable references; they only update when the underlying tool surface changes meaningfully.
